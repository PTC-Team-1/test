# CodeRabbit（コードラビット）使い方ガイド

**CodeRabbit** は、あなたが書いたコードをAIが自動でチェックして、改善点やバグを教えてくれる「AIコードレビューアシスタント」です。
先輩エンジニアにコードを見てもらう前の**「セルフレビュー（下書きチェック）」**や、**プログラミング学習の先生**として活用できます！

---

## 1. 基本的な使い方の流れ

すでにリポジトリに導入されているため、普段通りにGitHubで作業するだけで自動的に動きます。

### ステップ1：プルリクエスト（PR）を作る
いつも通りブランチを切ってコードを書き、GitHub上で **プルリクエスト（Pull Request / PR）** を作成します。
※すでに作成済みのPRに新しく `git push` した場合も自動で反応します。

### ステップ2：少し待つ（1〜3分ほど）
PRを作ると、CodeRabbitが自動でコードを読み込み始めます。PRの画面にウサギのアイコンのコメントが投稿されるまで少し待ちましょう。

### ステップ3：変更のまとめ（サマリー）を読む
最初に、CodeRabbitから**「今回のPRで何を変更したのか」の要約コメント**が届きます。
自分が意図した通りの変更になっているか確認しましょう。

### ステップ4：コードへのアドバイスを確認する
「Files changed（変更されたファイル）」タブやコメント欄を見ると、コードの特定の行に対してアドバイスが付いています。
- **バグの指摘**：「この書き方だとエラーになる可能性があります」
- **改善案**：「こう書くとよりスッキリして読みやすくなります」
- **セキュリティの注意**：「パスワードなどの機密情報がそのまま書かれています」

### ステップ5：コードを直す
指摘を見て納得したら、手元のエディタでコードを修正して再度 `git push` します。
また、CodeRabbitのコメント内に **「Commit suggestion（提案を反映）」** というボタンが出ている場合は、そのボタンを押すだけでGitHub上で直接コードを修正することもできます。

## 2. AIに質問・お願いをする方法（チャット機能）

CodeRabbitは、ただ指摘するだけでなく**会話（質問）**ができます。わからないことがあれば、どんどん聞いてみましょう！

### 指摘の内容がよくわからないとき
CodeRabbitのコメントの下にある「Reply（返信）」欄に、そのまま日本語で質問を書きます。

> **質問の例：**
> 「なぜこの書き方だとエラーになるのですか？初心者向けにわかりやすく教えてください。」
> 「この修正案のコードがどういう動きをしているか解説してください。」

### 便利な指示コマンド一覧
PRのコメント欄に `@coderabbitai` をつけて以下の言葉を送ると、特別な作業をしてくれます。

| 入力するコマンド | やってくれること | こんな時に使う |
| :--- | :--- | :--- |
| `@coderabbitai review` | もう一度レビューしてもらう | コードを直してプッシュしたのに反応がない時 |
| `@coderabbitai summary` | 変更のまとめを更新する | たくさん修正して、最初の要約と内容が変わった時 |
| `@coderabbitai generate docstrings` | コードの説明コメントを書く | 関数やメソッドに「何をする処理か」のメモ（コメント）を自動で作ってほしい時 |
| `@coderabbitai generate unit tests` | テストコードを作る | 自分のコードが正しく動くか確かめるための「テストコード」の例を書いてほしい時 |
| `@coderabbitai pause` | 自動レビューを一時停止する | まだ作業途中で、完成するまでレビューを待ってほしい時 |
| `@coderabbitai resume` | 自動レビューを再開する | 一時停止していたレビューを再び動かしたい時 |

## 3. 学習中におすすめの活用コツ

- **まずは「Draft（ドラフト）PR」で作ってみる**
  「まだ完成していないけど、とりあえずAIにチェックしてほしい！」という時は、PR作成時に **Draft pull request** として作成するのもおすすめです。（※設定によってはDraftでは動かない場合があるため、動かなければ `@coderabbitai review` とコメントしてみてください）
- **すべての指摘を完璧に直さなくても大丈夫**
  CodeRabbitは細かい改善案もたくさん出してくれます。「なるほど、そういう書き方もあるんだな」と参考にするだけでも勉強になります。迷ったら、そのまま返信欄で「この修正は必須ですか？」と聞いてみましょう。
- **他の人のPRのレビューも読んでみる**
  チームメンバーのPRに対するCodeRabbitのコメントを読むと、「どんな点に気をつけてコードを書けばいいのか」が自然と身につきます。
